# Hesiva

## Vision

Hesiva is an offline-first desktop application for tracking customer balances, payments, and reminders.

It is designed for small businesses that need a reliable, simple, and fast way to manage customer accounts without the complexity of full accounting software.

The first target audience is livestock veterinarians, but the software should remain generic enough to be adapted to other small businesses.

---

## Philosophy

The application follows a few core principles.

### Reliability first

Data integrity is more important than new features.

The application should never risk losing customer records.

### Offline first

The application must work completely without an internet connection.

Internet access should never be required for normal operation.

### Simple interface

The user should be able to learn the software within minutes.

The interface should stay clean and avoid unnecessary menus and dialogs.

### Fast workflow

Common operations should require as few clicks as possible.

Searching, adding transactions, and receiving payments should all be fast.

### Long-term stability

Updates should be rare and only released when necessary.

Avoid changing the interface unless there is a clear benefit.

### Transparency

Customer balances are always calculated from transaction history.

No hidden calculations.

Everything should be traceable.

---

## What this software is NOT

This is not an ERP.

This is not an accounting suite.

This is not an inventory management system.

Inventory or ERP-like features may be considered only after Version 1 if a concrete need appears. They must not influence the Version 1 design.

---

## Success criteria

The software replaces the existing legacy debt-tracking application.

A user who has never seen the software should be able to perform daily tasks with minimal training.

The application remains reliable even after years of continuous use.

No customer data is lost.
